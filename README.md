NxNameGradient Plugin

What is NxNameGradient?
Adds smooth gradient colours to player names.

Features:
Lightweight, DataBase Support, Fully Customizable , Easy to Use

14+ Premade Gradients

Custom Placeholders
%nxnamegradient_name% - for show name in gradient
%nxnamegradient_name_legacy% - for show gradient name in chat (for chat formatter plugins)
